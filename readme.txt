Display the logged-in user's avatar, name, and a customizable message in a Gutenberg block.

== Description ==

Avatar Menu is a simple and modern WordPress plugin that lets you show the current user's avatar and name inside a block. It's perfect for personal dashboards, member areas, or user-centric sites.

* Fully integrated with the block editor
* Lightweight and fast
* Responsive by default

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/avatar-menu` directory, or install via the WordPress plugin screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Use the "Avatar Menu" block in your pages or templates.

== Frequently Asked Questions ==

= Will it work with any theme? =
Yes, it uses standard WordPress functions and integrates with any theme that supports the block editor.

= Can I show a custom message? =
Yes, you can personalize the output via the block interface.
